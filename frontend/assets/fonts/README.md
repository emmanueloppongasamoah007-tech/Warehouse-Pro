Place font files used by the design system in this folder.

Required font filenames (used by the app and Tailwind tokens):

- `IBMPlexSans-Regular.ttf`
- `IBMPlexSans-Bold.ttf`
- `JetBrainsMono-Regular.ttf`

You can obtain these from the font vendors or Google Fonts. Restart the Expo dev server after adding fonts.
